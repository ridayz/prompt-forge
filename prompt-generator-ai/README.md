# Prompt Generator AI

Transform human language into precise, structured AI prompts. Generate prompts that are never off-topic and always exceed expectations.

## Features

- **Role Selection**: Choose from predefined roles (Developer, Designer, Data Scientist, Expert Advisor Trader, etc.)
- **Customizable Constraints**: Set tech stack, tone, detail level, and output format
- **Smart Templates**: Quick-start templates for common use cases
- **Dark/Light Mode**: Toggle between themes
- **History**: Save and reload previous prompts

## Prompt Structure

Generated prompts include:

1. **ROLE** - AI role and expertise context
2. **TUGAS** - Your task in natural language
3. **KONSTRAIN** - Tech stack, tone, detail level
4. **FORMAT OUTPUT** - Output structure preferences
5. **SUKSES** - Success criteria
6. **ANTI-PATTERN** - What to avoid

## Usage

1. Open `index.html` in your browser
2. Enter your task in natural language
3. Select role and constraints
4. Click **Generate Prompt**
5. Copy the generated prompt
